# Telegram-бот очередей

Бот ведет три независимых вида работ:

- субботняя уборка спального помещения: очередь спального помещения, командир участвует;
- уборка туалета: очередь отделения, командир не участвует;
- ежедневная утренняя уборка спального помещения: два человека, строгий круг без командира, с механизмом "взять взаймы" и долгами.

Все состояние хранится в JSON-файле `bot_data.json`. Базы данных нет.

## Запуск

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

В `.env` нужно указать:

```env
BOT_TOKEN=токен_бота_от_BotFather
ADMIN_TELEGRAM_ID=telegram_id_Шарова
DATA_PATH=bot_data.json
TZ=Europe/Moscow
```

Запуск:

```powershell
python -m bot.main
```

## Как начать пользоваться

1. Каждый человек пишет боту `/start`.
2. В появившемся списке выбирает свое имя.
3. Бот сохраняет соответствие Telegram-пользователя и имени в `bot_data.json`.
4. Администратор после `/start` получает кнопку админ-панели.

## Команды и кнопки

- `/start` - привязка Telegram к человеку или открытие меню.
- `/menu` - открыть меню.
- `/queue` - показать субботние работы на ближайшие 3 недели.
- `/admin` - админ-панель.

В админ-панели есть:

- задать начало круга субботней уборки;
- заменить назначенного;
- добавить второго человека на усиленную уборку с зачетом `0.5 + 0.5`;
- отметить, что субботней или утренней уборки не было;
- перезапустить утренний круг с завтрашней пары.

## Уведомления

- В пятницу в 18:00 по Москве бот уведомляет назначенных на субботние работы.
- Каждый день в 21:00 по Москве бот уведомляет двух назначенных на утреннюю уборку следующего дня.

Если назначенный на субботнюю уборку нажимает "Я не смогу по уважительной причине", бот спрашивает причину и отправляет ее админу с кнопками "Заменить" или "Оставить".

Если назначенный на утреннюю уборку нажимает "Я не смогу, взять взаймы", бот назначает следующего по строгому утреннему списку, пропуская уже назначенного на этот же день. Когда очередь дойдет до человека, который дал взаймы, вместо него выйдет должник.
